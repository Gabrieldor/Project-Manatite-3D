- 2026-08-09 — **Bug fix, found while verifying the hit marker**: `Weapon._ownerCollider` had been `null` for the player since the ship's 6x-scale pass — its hull colliders live on `Model/Cube` and `Model/Cube (1)` (nested children), but `Weapon.Awake()` looked upward via `GetComponentInParent<Collider>()`, which only checks the object itself and ancestors.
